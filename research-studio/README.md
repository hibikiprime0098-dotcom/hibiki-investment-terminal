# Investment Research Studio — 国内株・海外株 2タブ版

公開予定URL:
https://hibikiprime0098-dotcom.github.io/hibiki-investment-terminal/research-studio/

## 画面
- 国内株ランキング／海外株ランキングの2つだけ。直接関連・二次波及・間接関連は各企業の分類欄へ統合
- 投資可能額（万円単位、1万円刻み）と円換算参考レート、国内株の1/100/200株の概算
- 企業クリックで分析情報、PER・PSR・P/FCF、リスク、一次資料、外部TradingViewチャートを表示
- 財務安全性30・株価評価25・キャッシュ創出20・成長15・事業持続10点
- 根拠が足りない企業は点数を確定せず「追加調査順位」として表示。割安度はP/FCF→PER→PSRを優先参照する暫定的な業種横断比較であり、完全に公平なバリュエーション順位ではない
- 既存Excelの投資モデルは折り畳み表示。ランキングが変わっても配分額は自動的には変わらない

## 配当・優待
- `data/corporate_actions.csv` は個別IR確認済みの配当の一次出典だけを登録
- 未登録企業の配当は「未確認」であり「無配」を意味しない
- 配当額・IR資料の期日は必ず確認。古い確定配当を翌年の予想とみなさない
- ★ウォッチ登録すると、確認済み配当資料のある企業をサイト内メモで表示。ブラウザを閉じた状態でのプッシュ通知や未来の権利確定日通知は未対応
- 株主優待はランキング0点。最低株数・長期保有条件は投資前に公式IRで確認

## データ・更新
- `data/companies.csv`: 企業の調査スナップショット、詳細、指標
- `data/allocation_models.csv`: 6つの投資予算を補間する既存配分モデル
- `data/value_chains.csv`: 二次波及仮説を企業詳細へ表示
- `data/quotes.json`: 外部EOD終値。未設定なら参考株価
- 参考FXはFrankfurter外部APIに接続を試行。取得不可なら手入力・保存値が使用されるため最新ではない
- 金額、為替の手入力値、ウォッチ銘柄はブラウザのlocalStorageだけに保存。GitHub公開CSVにユーザーの資金額を保存しない
- 海外株のTradingViewチャートは外部埋め込み。サービス側の対応状況、遅延、通信制限に依存し、表示に失敗する場合はTradingViewへのリンクを用いる
- 配当更新や日本株の最新指標自動収集は未接続。GitHub Pagesが公開成功しても株価が自動更新されるわけではない

既存のリポジトリ直下の別アプリは変更していません。


## 2026-10-11 候補追加・スコア開示・指値参考モデル
- 日本の上場株候補：当初14社→47社（33社追加）。海外の対象31社と合わせて上場株78社。金融商品を含む母集団全体は81商品。
- 追加候補は量子（11社）・サイバー（13社）・AI/データセンター関連（23社）。独立した二次波及ページは設けない。
- 候補に入れる理由：量子/AI/サイバーの製品・技術を提供する直接関連、または技術普及の設備・素材・受注に連動する二次波及。実際の事業売上への貢献は別の確認項目とする。
- スコアは財務安全性30・割安度25・キャッシュ創出力20・成長率15・事業持続性10、株主優待0点。財務データ未確認銘柄は暫定的な調査順位を表示し、確定的なスコアや未来予測を付与しない。
- スコアの算式は「利用可能な項目の(評点×配点)の合計 ÷ 利用可能な項目の配点合計」。充足65%は使用した配点合計65点を指し、80点のスコアと混同しない。充足率は予測精度でも値上がり確率でもない。
- 暫定評点：財務安全性のA/B/C/Dは91/74/43/19点。割安度はP/FCF→PER→PSRで代理的にスコア換算。キャッシュ創出と割安度でP/FCFを重複使用している可能性があり、今後独立したFCFマージンデータへの置換が必要。
- 売上成長見通しは既存調査で転記済の予想を表示するのみ。会社ガイダンス/市場予測かの詳細・根拠URLは企業ごとに再検証。未掲載銘柄に予想値を捏造しない。
- 買付目安は2026-10-09の確認済終値や先行調査時参考値に、保守的な値下がり幅を設定する「指値検討シナリオ」。通常-10/-20%、PER>=28倍や景気循環AI部材は-15/-25%、PER>=35倍やリスクの高い小型株は-20/-30〜35%程度。これはEPS/DCFベースの理論株価ではない。基準価格と日付、算定理由、財務評価保留の有無を企業詳細に表示する。
- 新規銘柄のうち市場価格・EPS/PER/FCFが未確認の企業には価格を推測で埋めない。
- 参考データソースは企業・金融情報各リンク先を参照。著作権/データ配信利用規約に従い数値の無断再配信は避ける。自動市場価格取得は未設定。


## 2026-10-11: 5段階の価格・株価ウィジェット・財務補完
投資候補の各行に、直近の取得株価（基準日を表示）、買い検討開始、購入目標、売却検討開始、目標売却の5つを掲載。円換算はFrankfurter参照FXまたはユーザー手入力FXに依存。

**価格の位置付け:** 4つの売買閾値は発行体の公正価値ではなく、基準価格と業種・PER・PBR・利益の検証状況に応じた上下変動の**シナリオ**。高評価・高ボラティリティでは買いの待機幅を深く、売りの見直し水準を調整。投資を勧める客観的指値・EPS/DCFの適正価値は現時点では提供しない。株価基準日が7日超前なら警告。

**無料の最新マーケットデータ閲覧:** TradingView公式の Market Data / Symbol Info / Symbol Overview / Fundamental Data ウィジェットをサイト内に埋め込み。これは提供元自身の表示であり、取引所により遅延や対象銘柄制限がある。TradingViewウィジェット内の数字はJSやGitHubのCSVに自動取り込みできない。データが欠損した銘柄も、銘柄詳細で提供元の価格・財務が見られる場合がある。取得済みの数値と提供元ウィジェットの数値は異なる場合がある。

**株価を入力する方法:** 企業詳細の「確認した株価をこの画面の計算基準にする」で、提供元や証券アプリで確認した現地通貨の株価を入力すれば、ブラウザ内だけに保存され、その銘柄の5価格を計算し直す。GitHubへは送信されない。

**正式な財務データ:** 米国企業はSEC EDGAR CompanyFacts XBRLを自動照会する処理を同梱。現状、GitHub ActionsからSECへの通信制限により**取得0社**で、財務JSONは空。処理が失敗してもサイト公開は続行する。日本企業の最新財務・最新株価を銘柄全件で数値統合するには、別途適法な提供元へのAPI接続と権限が必要。J-Quants無料プランは12週間遅延なので現在値用途には使えず、株価API未設定状態をリアルタイム取得済みと表示しない。ETFや非SEC対象の海外企業についてもSECのJSON補完には対応しない。

**現状の数値取得済み:** 国内47社中21社、海外31社中19社の静的な基準価格を保持。残りは参考価格・財務比率を推測補完せず、外部提供元ウィジェットと詳細IRリンクを案内。業績予想の出典照合、独立したFCF・PBR・ROIC・自己資本比率データ取得の自動化は継続課題。

**GitHub Actionsの動作:** 平日（東京時間の月〜金朝頃）と手動実行時に価格API（キーがある場合）とSECを試行。ネットワーク制限やAPIキー欠落なら既存ファイルを保持。Actionsの成功はデータ更新成功を意味せず、各銘柄の取得日と掲載元で判断する。機密の証券口座情報・投資額は公開CSVに保存しない。
