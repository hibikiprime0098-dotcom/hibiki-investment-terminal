# Investment Research Studio

国内株・海外株を分けて量子計算、セキュリティ、関連インフラ企業を研究するWebサイト。

- `index.html` をGitHub Pagesの `/research-studio/` で公開
- `data/` に企業情報、予算別配分、バリューチェーン、３レポート共通度をCSVで保持
- 株価は2026-10-08/09時点の参考値を初期収録。実際の取引時点の価格ではありません
- 投資資金・ウォッチリストはブラウザ内(localStorage)にのみ保存
- 株式注文・証券口座との接続は行いません
- `data/quotes.json` は初期状態では未設定。リアルタイム・日次自動更新は別途データ契約・定期実行設定が必要です

既存のルートアプリには変更を加えません。
